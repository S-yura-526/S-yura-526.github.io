YURA PORTFOLIO 公開用ファイル

このZIPには最新のHTML / CSS / JavaScriptが入っています。

公開前に、手元のPORTFOLIOフォルダで使用している「images」フォルダを
このフォルダ直下にコピーしてください。

最終構成:
YURA_PORTFOLIO_FINAL/
├── index.html
├── about.html
├── works-personal.html
├── works-client.html
├── works-school.html
├── style.css
├── script.js
└── images/
    ├── favorites/
    ├── profile/
    ├── skill/
    ├── top/
    └── works/

Netlifyへ公開する場合は、このフォルダ全体をドラッグ&ドロップします。
